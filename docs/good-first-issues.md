# Good first issues · 新手任务

Personal-AI-OS lets people self-host their own personal assistant, Yimi (依米). These small contributions improve the real 0.0.1 contributor experience. Pick one and open an issue before starting so two people do not duplicate the work. File references are relative to the public tree; line numbers describe the initial source snapshot and may move.

每项只做列出的范围。默认使用合成数据和本地测试，不连接真实账号或设备。测试环境见 [testing.md](testing.md)，环境搭建见 [first-run.md](first-run.md)。
